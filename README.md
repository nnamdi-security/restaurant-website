# 🍝 La Veranda Italian Cuisine — Restaurant Website

A fully responsive, multi-page restaurant website built as a collaborative group project. The site showcases an authentic Italian dining experience with a clean, elegant design, intuitive navigation, and rich content across five pages.

**🔗 Live Site:** [nnamdi-security.github.io/restaurant-website](https://nnamdi-security.github.io/restaurant-website/)

## 📄 Pages

| Page | Description |
|------|-------------|
| **Home** | Hero section, restaurant introduction, featured menu highlights, and location preview |
| **Menu** | Full menu with four categories — Starters, Main Courses, Desserts, and Beverages — each with images and prices |
| **About Us** | Restaurant history, mission statement, chef profile, and interior gallery |
| **Gallery** | Visual showcase of the restaurant's ambience and dishes |
| **Contact** | Reservation/contact form, opening hours, address, and an embedded Google Map |

---

## ✨ Features

- Fully responsive layout — works across desktop, tablet, and mobile
- Multi-page navigation with a consistent header and footer
- Menu page with categorised dishes, food photography, and pricing
- Contact page with a reservation form and embedded Google Maps
- Chef profile and restaurant story on the About page
- Consistent branding and Italian-themed aesthetic throughout

## 🚀 Getting Started

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/nnamdi-security/restaurant-website.git

# Navigate into the project folder
cd restaurant-website

# Open in your browser
open index.html
```

No build tools or dependencies are required — it's plain HTML, CSS, and JavaScript.
